# Gallery Card Separation Implementation Guide

## Overview
This document explains the implementation of year-specific card views for the gallery section of the Ganesh Festival website. Each year (2023, 2024, 2025) now has its own set of card images that are dynamically loaded based on the available images in each year's `card-images` subdirectory.

## Implementation Details

### JavaScript Changes

1. **Card Configuration Mapping**: Added a `cardConfig` object that maps card image names to their corresponding gallery folders and translation keys.

2. **Dynamic Card Loading**: 
   - `loadCardDataForYear(year)`: Loads and caches card data for each year
   - `imageExists(imagePath)`: Checks if card image exists before displaying
   - `displayCardsForYear(year)`: Dynamically creates and displays cards based on available images

3. **Year Switching**: Updated `switchYear(year)` function to load cards specific to the selected year.

4. **Image Count Management**: `getImageCount(folderName)` provides accurate counts for each gallery folder per year.

### HTML Changes

- Removed hardcoded card HTML elements
- Cards are now dynamically generated by JavaScript based on available images in each year's `card-images` folder

## How to Add New Cards

### Step 1: Add Card Image
Place the new card image in the desired year's `card-images` folder:
```
images/gallery-images/[YEAR]/card-images/[CARD_NAME].avif
```

### Step 2: Update Card Configuration
Add the new card to the `cardConfig` object in `functions.js`:
```javascript
const cardConfig = {
  // existing cards...
  'new-card-name.avif': {
    folderName: 'NewFolderName',
    translationKey: 'new-card-text'
  }
};
```

### Step 3: Update Default Text Mapping
Add translation text in the `getTranslationText` function:
```javascript
const defaultText = {
  // existing texts...
  'new-card-text': 'New Card Display Name'
};
```

### Step 4: Update Image Counts
Add the folder and its image counts to the `getImageCount` function:
```javascript
const imageCounts = {
  'NewFolderName': {
    '2023': 5,
    '2024': 7,
    '2025': 6
  }
};
```

### Step 5: Create Gallery Folder
Ensure the corresponding gallery folder exists with images:
```
images/gallery-images/[YEAR]/[NewFolderName]/
```

## Features

### Dynamic Loading
- Cards are loaded asynchronously based on available images
- Loading states and error handling included
- Cached card data for better performance

### Year-Specific Cards
- Each year can have completely different sets of cards
- Cards only appear if both the card image and gallery folder exist
- Automatic count detection for carousel images

### Responsive Design
- Cards maintain existing responsive layout
- Scroll buttons work with dynamically loaded cards
- Translation support maintained

## Error Handling

- **Missing Card Images**: Cards won't appear if image doesn't exist
- **Missing Gallery Folders**: Cards won't appear if no images in gallery folder
- **Loading Errors**: User-friendly error messages displayed
- **Empty Years**: Shows "No cards available" message

## Performance Optimizations

- **Caching**: Card data is cached per year to avoid repeated loading
- **Async Loading**: Cards load asynchronously without blocking UI
- **Idle Callback**: Initial loading uses `requestIdleCallback` for better performance

## Maintenance Notes

- To add/remove cards for a specific year, simply add/remove images from that year's `card-images` folder
- Image counts should be updated in the `getImageCount` function when gallery folders change
- Translation keys should be added to the translations.json file for multi-language support
- Card images should maintain consistent naming and format (AVIF recommended)
